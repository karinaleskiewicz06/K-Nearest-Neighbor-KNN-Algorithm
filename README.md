# K-Nearest-Neighbor-KNN-Algorithm

This repository contains a short presentation on the k-Nearest Neighbor (k-NN) algorithm and its fundamental concepts within the context of vector databases. It covers essential distance metrics (norms) and explores Approximate Nearest Neighbor (ANN) search techniques such as LSH, PQ, and HNSW. The slides are written in LaTeX using the Beamer class, and the source code can be easily compiled in environments like Overleaf to generate the final PDF.
