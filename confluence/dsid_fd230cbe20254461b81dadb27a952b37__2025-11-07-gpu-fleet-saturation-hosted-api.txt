Postmortem: Hosted API latency spike due to GPU fleet saturation (2025-11-07)

h2. Summary
On 2025-11-07, the Hosted API experienced elevated p95 latency and intermittent 503s. The primary driver was GPU fleet saturation in us-east caused by a bursty customer workload combined with delayed scale-out of the shared A100 pool.

h2. Customer impact
* Time window: 09:12–10:26 PT
* Symptoms: long queue wait time, slow streaming starts, occasional 503 "no capacity" responses
* Affected: hosted API traffic in us-east (spillover increased load in us-west)

h2. Detection
* #incidents page triggered from alert: "gpu_pool_free_slots < 1 for 10m"
* Support received multiple reports of slow responses on /v1/chat/completions

h2. Root cause
Capacity allocator throttled scale-out due to a stale regional quota cache. Autoscaler continued to request nodes, but provisioning was rate-limited and the allocator did not reroute early enough.

h2. Contributing factors
* Regional A100 quota headroom was lower than forecasted for November peak
* Routing policy did not shift traffic until queue depth exceeded 500
* Runbook step to validate quota cache freshness was missing

h2. Resolution
* Forced refresh of quota cache and increased target capacity
* Temporarily lowered routing threshold to shift excess traffic to us-west
* Enabled burst pool for high-priority hosted tier
